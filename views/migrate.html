🔄 图片数据迁移

如果您发现原有的图片无法显示，可能是因为这些图片还没有被添加到 PostgreSQL 数据库中。 使用下面的工具可以将所有现有图片迁移到 PostgreSQL 数据库中。

📋 迁移说明

  • 此工具会扫描 uploads 目录中的所有图片文件
  • 只会添加未在 PostgreSQL 数据库中记录的图片
  • 不会影响现有的图片记录
  • 操作完成后所有图片都将正常显示
  • 建议在低峰期执行此操作

💾 PostgreSQL 数据库管理

PostgreSQL 数据库管理工具，用于SQL格式备份、恢复和维护图片数据。

🛠️ 数据库功能

  • SQL备份: 将 PostgreSQL 数据导出为 SQL 文件备份
  • SQL恢复: 从服务器上的 SQL 备份文件恢复数据
  • 上传恢复: 上传本地 SQL 文件进行数据恢复
  • 自动备份: 设置定时自动备份，确保数据安全
  • 备份管理: 查看和管理所有备份文件
  • 兼容支持: 仍支持 JSON 格式的导入导出
  • 所有操作都是安全的，支持事务回滚

🔄 SQLite 数据导入

从旧的 SQLite 数据库导入数据到当前的 PostgreSQL 数据库中。支持从 SQLite 数据库文件、JSON 备份文件或上传的文件导入。

📋 SQLite 导入说明

  • 自动检测: 系统会自动检测并导入现有的 SQLite 数据库文件
  • JSON 导入: 支持从 SQLite 导出的 JSON 备份文件导入
  • 文件上传: 支持上传 SQLite 数据库文件(.db) 或 JSON 备份文件(.json)
  • 重复处理: 相同路径的图片记录不会重复导入
  • 数据完整性: 导入过程中会验证数据完整性
  • 事务安全: 导入失败时会自动回滚，确保数据安全
